# 🛍️ Foodgo — Customer Experience & Storefront Manual

The **Foodgo Customer Storefront** (`index.html`) is a high-speed, app-like Progressive Web Application (PWA) providing a seamless food and multi-service shopping experience.

---

## 📱 Customer Features & Flow

1. **Multi-Service Module Selector**:
   - Switch seamlessly between **Food**, **Grocery**, **Pharmacy**, **Cosmetics**, and **Stationery**.
   - Categories and catalog items dynamically update upon selecting a module.

2. **Interactive Burger & Item Customization**:
   - Custom portion counter (+ / -).
   - Spicy level slider (0% Mild to 100% Extreme Hot).
   - Topping selectors (Onions, Extra Cheese, Tomato, Jalapenos, Mushrooms).
   - Side order addons (French Fries, Coleslaw, Drink upgrades).
   - Salna / Curry selection for combo dishes.

3. **Cart & Direct Checkout**:
   - View item subtotal, delivery charges, and local taxes.
   - Apply discount coupons (e.g. `WELCOME50`, `FOODGO20`).

4. **Multiple Payment Modes**:
   - Instant UPI QR code (Google Pay, PhonePe, Paytm, BHIM).
   - Credit / Debit Card simulation.
   - Cash on Delivery (COD).

5. **Live Order Tracking**:
   - Real-time status tracker (`Order Placed` ➔ `In Kitchen` ➔ `Out for Delivery` ➔ `Delivered`).

6. **2-Way Chat Support & Voice Notes**:
   - Send live text messages.
   - Record audio voice messages using device microphone for instant support response.
