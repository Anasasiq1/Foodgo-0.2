# 💬 Foodgo — WhatsApp Business API Integration

Foodgo provides optional automated **WhatsApp Order Alerts** to deliver real-time order receipts, live kitchen status updates, and rider tracking links directly to customer phones.

---

## ⚡ Features

- **Customer Receipts**: Sends branded order summary and invoice link upon checkout.
- **Kitchen Alerts**: Notifies restaurant managers of new high-priority orders.
- **Rider Dispatch**: Sends customer address and GPS coordinates directly to assigned delivery partners.
- **Non-blocking**: If WhatsApp API is not configured or offline, Foodgo processes orders normally without interruption.
